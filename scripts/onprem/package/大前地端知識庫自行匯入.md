# Arcrun 地端版：知識庫自行匯入（給現場 IT）

> 票：inkstone/arcrun-rag#339。這一頁給「已經裝好 Arcrun 地端版、要自己把知識庫放進去」的人看。
> 不需要連外網、不需要 node，只需要原本那台的 Linux＋Docker＋bash＋sha256sum。

## 你會拿到什麼

一個 `kb/` 資料夾，加一份新的 `SHA256SUMS`：

| 檔案 | 用途 |
|---|---|
| `kb/kbdb.sqlite` | 知識庫本體（約 580 MB）。若拿到的是 `kb/kbdb.sqlite.000`、`.001`…分段，先照下面「0.」接回來 |
| `kb/vectors.sqlite` | 語意搜尋用的向量檔 |
| `kb/MANIFEST.json` | 快照清單：筆數、租戶名、上面兩個檔的 sha256 |
| `SHA256SUMS` | 整個安裝包（含新知識庫）的 sha256 清單，**要蓋掉安裝包裡原本那一份** |

## 前提

- 從專案資料夾或隨身碟複製下來的 `install.sh` 可能沒有執行權限，本頁一律寫成 `bash install.sh …`。
- 這台已經跑過 `bash install.sh up`（容器 `arcrun` 起來了）。
- **還沒走精靈**。匯入會整個換掉知識庫檔，連同精靈建的管理員一起換掉。
  已經走過精靈：指令前面加 `WIPE=1`，匯入後重新走一次精靈（管理員要重設）。

## 步驟（都在安裝包資料夾裡做）

**0. 若拿到的是分段，先接回整檔**（沒有分段就跳過）

```sh
cat kb/kbdb.sqlite.??? > kb/kbdb.sqlite && rm kb/kbdb.sqlite.???
cat kb/vectors.sqlite.??? > kb/vectors.sqlite && rm kb/vectors.sqlite.???   # 有分段才做
```

**1. 把 `kb/` 三個檔和新的 `SHA256SUMS` 放進安裝包資料夾**（蓋掉舊的）。

**2. 驗、匯入、確認：一行**

```sh
sha256sum -c SHA256SUMS && bash install.sh import && bash install.sh status
```

- `sha256sum -c` 每一行都要是 `OK`。有任何 `FAILED`＝檔案複製不完整，重新複製那個檔，不要往下做。
- `bash install.sh import` 會再驗一次 sha256、檢查容器租戶與快照一致、停容器換檔、重開，最後拿 `kb/MANIFEST.json` 的筆數逐類比對。
  看到 **`✓ 與快照清單一致`** 才算匯入成功。
- 已經走過精靈的話，那一行改成：`sha256sum -c SHA256SUMS && WIPE=1 bash install.sh import && bash install.sh status`

## 怎麼確認成功

1. `import` 的最後一行是 `✓ 與快照清單一致`，上面印的 `entries` 筆數等於 `kb/MANIFEST.json` 裡的 `"entries"`。
2. `bash install.sh status` 的「知識庫：N 筆」等於同一個數字。
3. 瀏覽器開 UI 網址走精靈；走完後跑 `bash install.sh n8n-test`，三個知識庫（`lib_473ed4`、`lib_1e221c`、`error_codes`）都要打勾、錯的金鑰要回 401。
4. 想再抽查一題：Portal 知識庫搜尋 `145-0010`，要搜得到 145-0010 那兩張卡。

## 失敗時

| 看到 | 原因 | 怎麼做 |
|---|---|---|
| `sha256sum` 某行 `FAILED` | 複製不完整 | 重新複製那個檔 |
| `容器租戶是「…」，快照是「…」` | 容器建的時候租戶不對 | `docker rm -f arcrun` 後 `bash install.sh up`（資料卷不動）再匯入 |
| `這台已走完精靈` | 已經走過精靈 | 用 `WIPE=1` 那一行，匯入後重走精靈 |
| `容器 3 分鐘內沒變健康` | 容器起不來 | `docker logs arcrun` 把最後 50 行交給原廠 |
| `✗ entries … ≠ …` | 檔案與清單不合 | 不要用這台的資料，把整段輸出交給原廠 |
