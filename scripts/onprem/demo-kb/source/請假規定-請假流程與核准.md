# 示範科技公司請假規定：怎麼請假（請假流程、要提前幾天、誰核准）

> 本文件是示範用的虛構公司規定，用來展示知識庫問答，不是任何真實公司的規章，也不構成法律意見。

1. 在公司差勤系統「我的請假」填寫申請，選假別、起訖時間與職務代理人。
2. **事假與特休**要在 **3 個工作天前**提出。
3. 連續請 **3 天以上**，要**直屬主管與人資部**都核准；3 天以下只要直屬主管核准。
4. **病假與喪假**可以事後補請，但要在**回到工作崗位後 3 個工作天內**補完手續與證明。
5. 請假的最小單位是 **1 小時**。
6. 沒有依規定請假就缺勤，以曠職論。

## 聯絡窗口

有任何請假問題，請洽人資部（分機 1234，信箱 hr@demo.example）。
