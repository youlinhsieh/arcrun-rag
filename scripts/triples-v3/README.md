# triples-v3 驗收評測（inkstone/arcrun-rag#299）

只讀卡、不寫任何卡。原 `daqian/triples-v3/cs4.py` 只在 Mac，雲端找不到，這裡依策略文件重建最小評測；
v2 是依 `collector/extract_prompt_legacy.go` 的 facts 規則加「截 4000 字」重建的，不是原檔。

## 怎麼跑
```
export CLOUDFLARE_ACCOUNT_ID_YOULIN=… CLOUDFLARE_API_TOKEN_YOULIN_CC_USE=…   # 雲端 leo21c-dev 環境已有
cd scripts/triples-v3
python3 cs4_eval.py <卡片路徑清單> <輸出資料夾> --budget 0.8 --workers 6   # v2 vs v3，並出題、整張卡對照
python3 summarize.py <輸出資料夾>/results.jsonl
python3 cs4_v31.py <輸出資料夾>/results.jsonl <v31輸出資料夾> --budget 0.8 --workers 6   # 同一批題重量 v3.1
python3 summarize31.py <v31輸出資料夾>/results31.jsonl
python3 cs4_v3t.py <輸出資料夾>/results.jsonl <v3t輸出資料夾> --budget 0.9 --workers 6   # v3 提示不改＋容錯解析
python3 summarize3t.py <v3t輸出資料夾>/results3t.jsonl
```
## 怎麼換卡源
`<卡片路徑清單>` 是純文字檔，一行一個 md 路徑，改成別的資料夾的卡即可（例如 Mac 上大前的 `.wiki/` 文件卡）。
清單裡的卡要有 800 字以上、非表格卡才有意義；腳本不挑檔。同一份清單可續跑（已有結果的卡跳過）。
不要把結果檔（含卡片內文）提交進 repo。

| 占整張卡 | 100% | 65% | 83% | 72% |

- v3 比 v2 高約 18 點；長卡（>4000 字）v2 50%、v3 82%。門檻 85% 差 2 點。
- v3 初次回空清單約 6%：多為模型吐出壞掉的 JSON（少括號、一行多個 JSON 物件）。排除這些空卡後 v3 占整張卡 84.7%。
- v3.1（逐字保留、原因與做法單獨一條、不編造、空欄位／代稱機械檢查重抽、仍壞的條目丟棄）**沒有改善，反而退步**：
  空清單的卡從 6 張增到 23 張（同樣是壞 JSON），就算只比兩版都有結果的 174 張卡，v3.1 也只有 79.9%，低於 v3 的 84.7%。
  代稱／空欄的卡從 34% 降到 0%，但丟掉的條目與較長的條目換來的是答題變差。
- 下一步建議：先做「容錯解析」（從模型回文用規則撈出每一個三元組，而不是整份當 JSON 解），再量 v3；v3.1 的規則不要直接採用。
- 花費（估，單價憑記憶 scout 每百萬 $0.27 入／$0.85 出，未查證）：v2／v3 約 $0.82、v3.1 約 $0.46。

## v3＋容錯解析（v3t）：同批 200 張卡、同批 398 題、同一個判分（總監裁決 c1794277750959295）
| | 整張卡 | v2 重建 | v3 | v3t |
|---|---|---|---|---|
| 答對率 | 97.7% | 64.8% | 82.4% | 83.9% |
| 占整張卡 | 100% | 65% | 83.0% | **84.8%**（門檻 85%，差 0.2 點） |
| 空清單的卡 | | 1 | 6 | **0** |
| 長卡（>4000 字）答對率 | 98% | 50% | 82% | 89% |

- 容錯解析（`cs4_v3t.py` 的 `parse_facts_tolerant`）：JSON 解得出就用；解不出就用規則逐條撈 `["主詞","述詞","受詞"]`，撈到 0 條才重問（最多 3 次）。提示一字不改。
- 逐題對照 v3：只有 v3t 對 30、只有 v3 對 24、都對 304、都錯 40。兩邊都有「只有一邊對」，是模型每次回文略有不同造成的，30 對 24 在這個樣本數下不能當成確定的進步；確定的是空清單 6 → 0。
- 結論：**沒有到 85%（差 0.2 點）**，所以還不能把它定為 FactsRev 的萃取規格。能定的是兩件：① 解析一律容錯，不整份當 JSON 解；② v3 提示維持原樣（v3.1 的改法退步，不採用）。到 85% 與否要看大前卡的實測與門檻校正（整張卡本身也只有 97.7%）。
- 花費（估，單價憑記憶）：這一輪約 $0.29；v2／v3 約 $0.82、v3.1 約 $0.46，三輪合計約 $1.6。
