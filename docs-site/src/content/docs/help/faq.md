## 丟了檔案，但沒有產出知識卡

依序確認：

1. **檔案格式支援嗎**——Word／PDF／Excel／Markdown／純文字
2. **點「立刻同步」**看看，不要等
3. **看狀態列**——點小圖示，「狀態：」那行會說失敗原因

## 搜尋搜不到剛上傳的東西

**先確認你在哪個帳號**（portal 左下角）。
東西上傳到 A 庫、在 B 庫搜尋，當然搜不到——這是最常見的誤會。

## 更新完版本沒變

你的 App 可能不在「應用程式」資料夾。見[怎麼更新版本](../../use/update/)。

## 說我需要 Gemini API Key

**你不需要。** v0.15.6 起預設用你自己 Cloudflare 帳號內建的 AI，免金鑰。

如果還看到這個訊息，代表小幫手是舊版 → 重新下載最新版。

## 搜尋結果有一大堆重複的東西

已知問題：同一份檔案重複同步時，舊資料沒有被清掉，所以會堆疊。
我們正在修，**不影響你正常使用**（內容是對的，只是重複）。

## Mac 說「無法驗證開發者」

正常，我們還沒買 Apple 簽章。
**按住 Control 點 App → 選「打開」**。詳見[安裝（Mac）](../../start/install-mac/)。

## Windows 被 SmartScreen 擋下

正常，同樣是簽章問題。
**「其他資訊」→「仍要執行」**。詳見[安裝（Windows）](../../start/install-windows/)。

## 我的資料會被你們看到嗎

**不會。** 知識庫裝在**你自己的 Cloudflare 帳號**裡，
我們沒有你帳號的存取權。原始檔案也不離開你的電腦。
