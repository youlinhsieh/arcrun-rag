## 三句話講完

1. 桌面上的**同步小幫手**看守你指定的資料夾
2. 檔案丟進去 → 自動整理成**知識卡** → 存進**你自己 Cloudflare 帳號**裡的知識庫
3. 你的 AI 透過 **MCP** 連過來，就能查你的私人資料

:::note[不用花錢、不用申請 AI 金鑰]
用的是 Cloudflare 免費額度，整理檔案用你自己帳號內建的 AI。
原始檔案（Word／PDF）**不會離開你的電腦**。
:::
