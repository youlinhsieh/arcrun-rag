把你電腦裡的檔案，變成**你自己的 AI 能查得到的知識庫**。

## 你會得到什麼

- 丟一份檔案進資料夾 → 它自動整理成「知識卡」→ 之後問問題就查得到
- 支援 Word、PDF、Excel、Markdown、純文字
- **接到你平常用的 AI**（Claude、ChatGPT⋯），讓它直接查你的私人資料

## 三個角色，一句話分清楚

| 名稱 | 是什麼 | 裝在哪 |
|---|---|---|
| **同步小幫手** | 桌面上的小程式，看守你指定的資料夾 | 你的電腦 |
| **知識庫** | 存放整理好的知識卡、負責搜尋 | **你自己的 Cloudflare 帳號** |
| **portal 網頁** | 搜尋、問答、管理資料夾 | 同上 |

## 你的資料在哪？

**在你自己的 Cloudflare 帳號裡**，不是我們的伺服器。

原始檔案（Word／PDF）**不會離開你的電腦**——小幫手在本機把它轉成文字，
只有文字被送去整理成知識卡。

## 要花錢嗎？

不用。用的是 Cloudflare 免費額度，**也不需要申請任何 AI 金鑰**。

:::note
從 v0.15.6 起，整理檔案用的是你自己 Cloudflare 帳號內建的 AI，
**不必去 Google 申請 API Key**。想改用 Gemini 是進階選項，一般人不需要碰。
:::
