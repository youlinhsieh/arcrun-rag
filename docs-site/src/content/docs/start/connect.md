## 建立帳號

在安裝成功的畫面上，會請你設一組**帳號密碼**。
這是**你自己知識庫的帳號**，之後登入 portal 網頁要用。

## 讓小幫手連上

1. 點小圖示（Mac 在最上排選單列／Windows 在右下角工作列）
2. 選 **＋ 新增帳號…**
3. 貼上你的**知識庫網址**，輸入剛才設的帳號密碼

連上之後，選單會列出這個帳號，底下可以加資料夾。

:::tip[有多個知識庫？]
可以一直加。每個帳號各自管自己的資料夾，互不影響。

不過要注意：**搜尋的時候要確認自己在哪個帳號**，
不然會發生「東西明明有上傳卻搜不到」——因為你在另一個庫裡找。
:::

## 密碼會被存起來嗎？

**不會。** 密碼只在連線那一刻用一次，之後小幫手用一組專屬憑證跟你的知識庫溝通，
本機不留密碼。
