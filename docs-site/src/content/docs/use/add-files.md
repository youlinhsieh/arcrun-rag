## 加一個資料夾

點小圖示 → 該帳號底下的 **＋ 新增知識資料夾…** → 選一個資料夾。

從此**這個資料夾裡的檔案都會被自動整理**。

## 支援哪些檔案

Word（.docx）、PDF、Excel（.xlsx）、Markdown（.md）、純文字（.txt）。

:::note[原始檔不會離開你的電腦]
小幫手在**你的電腦上**把檔案轉成文字，只有文字被送去整理。
Word／PDF 檔本身不會被上傳。
:::

## 它整理出什麼

每個檔案會變成一張**知識卡**，存在該資料夾底下的
`system-dev/wiki/cards/` 裡。你可以直接打開看它整理得對不對。

一張卡長這樣：

```markdown
# 火星座標
## 一句話定義
火星的地理特徵標誌。

## 要點
- 赤道半徑約 3396 公里。
- 奧林帕斯山高度約 21.9 公里。

## 關鍵實體
- **奧林帕斯山** — 太陽系最高的火山。

## 關聯
- 奧林帕斯山 >> 位於 >> 火星北緯 18.65 度
```

## 要等多久

丟進去後大約 **5 秒內**會被發現，每個檔案整理約 **3 秒**。

想立刻跑一次：點小圖示 → **立刻同步**。

## 怎麼知道成功了

點小圖示，看「狀態：」那行。會顯示上次同步時間；
有失敗會顯示「⚠ 萃取失敗 N 檔」，點進去看原因。

## 刪掉檔案會怎樣

把檔案從資料夾刪掉 → 下次同步時，知識庫裡對應的內容也會下架，搜尋就查不到了。
