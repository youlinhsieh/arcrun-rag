## 加一個資料夾

**直接在小幫手的視窗裡加**，不用先去 Portal 或 Cloudflare 設定任何東西：

1. 點小圖示（Mac 在最上排選單列／Windows 在右下角工作列）開出小幫手的視窗。
2. 點左邊你的知識庫，再點右邊上方的 **資料夾** 分頁（資料夾圖示，滑鼠移過去會顯示名稱）。
3. 按右上角橘色的 **加資料夾** 鈕，選一個資料夾。

從此**這個資料夾（連同裡面的子資料夾）裡的檔案都會被自動整理**。
想不要了，按那一列右邊的垃圾桶移除。

## 支援哪些檔案

Word（.docx）、PowerPoint（.pptx）、Excel（.xlsx）、CSV、PDF、Markdown（.md）、純文字（.txt）。

:::note[原始檔不會離開你的電腦]
小幫手在**你的電腦上**把檔案轉成文字，只有文字被送去整理。
Word／PDF 檔本身不會被上傳。

例外：整份是掃描成圖片的 PDF 沒有文字可讀，小幫手會把那幾頁畫成圖，
送到**你自己的**知識庫雲端讀成文字。
:::

## 它整理出什麼

一份文件會變成**一張總覽卡＋幾張概念卡**，卡片之間有連結，每張都寫明出處。
卡片放在每一層有文件的資料夾裡、**隱藏的 `.wiki` 資料夾**，你可以直接打開看它整理得對不對。
你自己的原稿一個字都不會被改。

要看到隱藏的資料夾：

- **Mac**：在 Finder 按 ⌘ ⇧ .（Command＋Shift＋句點）
- **Windows**：檔案總管 → 檢視 → 顯示 → **隱藏的項目**

一張概念卡長這樣（示意）：

```markdown
# 火星座標
## 一句話定義
火星的地理特徵標誌。

## 要點
- 赤道半徑約 3396 公里。
- 奧林帕斯山高度約 21.9 公里。

## 關鍵實體
- **奧林帕斯山** — 太陽系最高的火山。

## 關聯
- 奧林帕斯山 >> 位於 >> 火星北緯 18.65 度
```

## 要等多久

丟進去後幾秒內就會被發現。整理要花多久，看檔案多大、有幾份。
當天的免費 AI 額度用完時會先暫停，隔天台北時間早上 8 點自動接著做，不用你處理。

想馬上跑一次：按視窗右上角的 **同步**（兩個箭頭繞圈的圖示）。

## 怎麼知道成功了

看**資料夾那一列的右邊**，那就是進度：

- **呼吸燈加 31/46**：同步中，已經送上 31 份、總共 46 份
- **打勾加數字**：整個資料夾都送上知識庫了
- **旁邊多一個 `!3`**：有 3 份送不上去。點它會帶你到出錯的那個檔，
  檔案那一列會寫原因（常見的是檔案太大、掃描檔讀不出字）和怎麼處理，
  做不到的可以直接按「回報」。

## 刪掉檔案會怎樣

把檔案從資料夾刪掉 → 下次同步時，知識庫裡對應的內容也會下架，搜尋就查不到了。
