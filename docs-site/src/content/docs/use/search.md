## 三種搜尋，各有各的強項

| 方式 | 適合什麼 | 例子 |
|---|---|---|
| **關鍵字** | 你**記得確切用詞** | 搜「奧林帕斯山」 |
| **語意** | 你**只記得大概意思** | 搜「火星上最高的山」 |
| **圖譜** | 想看**東西之間的關係** | 從「火星」展開看關聯到什麼 |

## AI 問答

在問答框直接問問題，它會去查你的知識庫，然後用**你自己的資料**回答，
並且附上出處，讓你知道答案是從哪份檔案來的。

## 搜不到？先確認這件事

**你在哪個帳號？** 看左下角的帳號名稱。

如果你有多個知識庫，東西上傳到 A 庫、卻在 B 庫搜尋，當然搜不到。
這是最常見的誤會。

## 為什麼語意搜尋會出現不太相關的東西

語意搜尋是「找意思接近的」，所以會連帶撈出一些邊緣的結果。
我們正在調整篩選門檻，讓不相關的不要出現。
