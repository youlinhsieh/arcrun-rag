# Arcrun RAG 封測說明

謝謝你幫忙測試。

**這件事的目的不是「多一個資料庫」，是讓你天天在用的 AI 看得到你的文件。**

你平常問 Claude 問題，它不知道你公司的規定、你的客戶合約、你去年的會議記錄——
因為那些在你電腦裡。這套工具做的事是：把你選的資料夾整理成知識，
然後**接到你自己的 AI**（Claude.ai、Claude Code…），讓它回答時看得到、還會附出處。

> **所以第八步才是重點**：前面七步是把庫建起來，第八步把它接到你的 AI。
> 如果你只做到第七步，等於只裝了一個搜尋網站——**請務必做完第八步**。

這是一套「把你電腦裡的文件變成可搜尋知識庫」的工具，讓你的 AI 理解你：
- 你選幾個資料夾，它在**你自己的電腦上**用 AI 讀懂內容、整理成知識卡，只把整理好的重點送上雲端。**原始檔案不會離開你的電腦。**
- 建立在你自己的 Cloudflare 雲端，你不用先申請，過程中會自動完成。

花大約 10–15 分鐘。**過程中任何一步卡住、看不懂、或跟這份說明對不上，請截圖告訴我**——
你遇到的每個卡點都是我們要修的東西，不用客氣。

## 你需要準備

- 一個收得到信的 email
- Mac 或 Windows 電腦
- Cloudflare 帳戶會帶您完成，不需先有

## 第一步：拿辨識碼

1. 打開[**首頁**](https://rag.arcrun.dev) 理解一下
2. 在 **1 填 Email，領取「辨識碼」** 填你的 email，送出
3. **去收信**（也請看垃圾信匣），信裡有一組辨識碼

![Arcrun RAG 首頁](guide_images/landing.png)

## 第二步：一鍵安裝

1. 回到 [**首頁**](https://rag.arcrun.dev) 
2. 在 **2 連結你的 Cloudflare 帳號，一鍵安裝** 按鈕，會跳到[安裝頁](https://install.arcrun.dev)，輸入 Email 及辨識碼
3. 按「開始安裝／更新」後跳到**Cloudflare 授權頁**（允許自動化安裝到你的 CF 帳號）按下「Authorize」（授權，自動建立/登入 CF 帳號）
5. 接下來自動執行：建立空間 → 建立資料庫 → 部署服務 → 安裝 AI 工作流 → 自我檢查
6. 完成後會跳出**專屬網址**（形如 `https://arcrun-rag-ui.xxxx.workers.dev`）——**就是你的知識庫**，點擊開啓知識庫首頁

> ⚠️ **如果中途出現紅字錯誤**：按「重新安裝」再試一次（進度會接續，不會重來）。
> **請把錯誤畫面截圖給我**，並告訴我試了幾次——我們正在修這一塊。
> 因為 CF 複雜難懂，這裡把申請過程隱藏了，不用學那些。

## 第三步：建立你的帳號

1. 打開剛剛拿到的專屬網址
2. 第一次進去會請你設定登入用的**帳號密碼**（這是你知識庫的管理員）

![知識庫登入頁](guide_images/portal-login.png)

> 此時已經在你自己的 CF 帳戶，我沒辦法幫你恢復帳密，請記住它

## 第四步：下載並打開「同步小幫手」

你有了總庫，還沒有加入知識，文件在你的電腦，所以下載「同步小幫手」：
1. 第一次進入知識庫首頁，右下角會有個小市場要你下載
2. 以後再次下載，在左側「設定/下載同步小幫手」下載

> 它類似 Google Drive 小軟體，不同的是：1）它同步到你的私有雲，不是我的公雲；2）不同步原文，只同步 AI 摘要。

## 第五步：連上你的知識庫

1. 點選單列的小幫手圖示 → 「**＋ 新增帳號…**」
2. 貼上你的專屬網址，輸入第三步設的帳號密碼
3. 連上後，選單會顯示你的帳號名稱

## 第六步：選資料夾，等它整理

1. 在你的帳號下面點「**＋ 新增知識資料夾…**」，選一個有文件的資料夾
   （支援 PDF、Word、Excel、PowerPoint、CSV、純文字、Markdown）
2. 建議**第一次先選少一點**（5–10 個檔案），比較快看到結果
3. 選單會顯示「**已萃 N 檔**」——那就是整理進度
4. 想立刻跑一輪，點「**立刻同步**」

### 🎯 這裡是重點：可以加很多個，而且會分開管理

**一台電腦、一個小幫手，可以同時掛多個資料夾、多個知識庫：**

- **多個資料夾**：一個資料夾 ＝ 雲端一個「庫」。
  你可以把「客戶合約」「產品文件」「會議記錄」各選一個資料夾，它們在雲端自動分成三個庫。
- **多個 Cloudflare 帳號**：點「**＋ 新增帳號…**」再連一個知識庫（例如「個人」和「公司」各一個）。
  選單會分成兩區、各管各的資料夾，**兩邊的資料互不相見**，也不用切換來切換去。

> 為什麼做得到？因為小幫手不像 Google Drive 要在你電腦上放一份副本——
> 它只是「讀完、整理、送重點」，所以掛幾個都很輕。

## 第七步：Show Time —— 先確認庫建對了

> 這一步是**驗收**：確認你的文件真的被讀懂、整理好了。
> 確認完，**第八步才是你以後每天會用的方式**。

回到你的知識庫網頁（就是你的專屬網址）。**這一步是整個封測的重點，請多玩一下。**

### 1️⃣ 三種搜尋，各有各的強項

在「**搜尋**」頁上方有三顆按鈕，同一個問題可以三種都試試看，感受差別：

| 模式 | 它在做什麼 | 什麼時候用 |
|---|---|---|
| **關鍵字** | 字面比對，快、精準 | 你記得確切用詞（人名、產品名、編號） |
| **語意** | 用「意思」找，不用字面一樣 | 你只記得大概在講什麼（例：搜「怎麼請假」找到「差勤管理辦法」） |
| **圖譜** | 沿著概念之間的關聯找 | 你想知道「這個東西跟什麼有關」 |

另外還有「**問 AI**」：直接用一句話問你的知識庫，它會回答**並附上出處**，
你可以點出處回頭驗證——**答案不是憑空生的**，這是它跟一般聊天機器人最大的差別。

### 2️⃣ ⭐ 跨庫搜尋（最想請你試的功能）

**右上角有一個「範圍」**，預設是「**全部知識庫**」。

意思是：你剛剛加的那幾個資料夾，**一次搜尋就全部一起找**——
不用先想「這份文件在哪個資料夾」，也不用一個一個資料夾翻。

> 請試試看：搜一個**只有某一個資料夾才有**的詞，看它是不是找得到、
> 而且結果會標出它來自哪個庫。
> 再把範圍切到單一個庫，比較一下差別。

**這正是它跟「在電腦上按 Cmd+F 找檔案」的分水嶺**：
你的知識被讀懂、被連起來，然後可以一次問全部。

### 3️⃣ 總圖：看知識自己長成一張網

點左側「**總圖**」，會看到你的文件被拆成一個個概念，以及它們之間的連線。
上面會寫「N 個實體・M 條關聯」。

> 這張圖不是我們畫的，是 AI 讀完你的文件後**自己整理出來的關聯**。
> 文件越多，這張網越密。

### 4️⃣ 管理：確認資料夾都上來了

左側「**管理**」→「**庫目錄管理**」：
你選的每個資料夾，都會自動變成一個「庫」出現在這裡，**不需要人工新增**。

> 如果你加了三個資料夾，這裡就該有三個庫。**沒出現的話請告訴我**——那是我們要修的。

## 第八步：⭐ 接到你自己的 AI —— 這才是重點

網頁裡的「問 AI」只是**讓你先試玩**。真正的用法是——
**把這個知識庫接到你平常在用的 AI**，讓它回答問題時看得到你的文件。

我們幫你在雲端裝好了一個 **MCP Server**（AI 用來連外部資料的標準介面）。

> **跟別人不一樣的地方**：市面上多數 MCP 要你在**自己電腦**上裝一支程式（stdio 模式）——
> 換一台電腦就要重裝、手機上根本不能用。
> **你剛剛裝的是雲端 MCP**：你的 AI 走網址連過來就好，這也是為什麼選擇放在 CF，因為它是全球數一數二的雲服務商，可以免費提供。
> **公司電腦、家裡電腦、手機、網頁版，全部通用，什麼都不用裝。**

**你的 MCP 網址**（把 `xxxx` 換成你自己的那串，跟知識庫網址同一組）：

```
https://arcrun-mcp.xxxx.workers.dev/mcp
```

### 接到 Claude.ai（網頁版／App）

1. 打開 **claude.ai** → 右下角或設定裡找「**Connectors**（連接器）」
2. 選「**Add custom connector**（新增自訂連接器）」
3. 貼上你的 MCP 網址，儲存
4. 它會跳出**授權畫面**，按同意（就是讓 Claude 有權讀你的知識庫）
5. 之後在對話裡直接問：「**根據我的知識庫，○○○的規定是什麼？**」
   它會去查你的文件並附出處

### 接到 Claude Code（終端機）

在你的專案資料夾裡跑一行：

```bash
claude mcp add --transport http arcrun https://arcrun-mcp.xxxx.workers.dev/mcp
```

然後 `/mcp` 檢查連上了沒；第一次會要你授權。
之後跟 Claude Code 講話時，它就查得到你的知識庫。

### 有多個知識庫？分別接上就好

**每個知識庫有自己的 MCP 網址，彼此獨立。** 如果你有兩個（例如「個人」和「公司」），
把兩個網址都加進去，你的 AI 會同時看得到兩邊：

- **Claude.ai**：重複「新增自訂連接器」的步驟，貼上第二個網址（各自授權一次）
- **Claude Code**：取不同名字加第二條
  ```bash
  claude mcp add --transport http arcrun-work https://arcrun-mcp.yyyy.workers.dev/mcp
  ```
  （第一條叫 `arcrun`、第二條叫 `arcrun-work`，名字自己取、不能重複）

> 加完之後問問題，AI 會自己判斷去哪一個知識庫找，或兩邊都找。

> **請幫我試這一段並回報**：接得上嗎？授權畫面看得懂嗎？
> 問一個「只有你文件裡才有的答案」，它答得出來嗎？有附出處嗎？

## 第四步之後：設定「誰來幫你讀文件」（第一次必做）

小幫手是用 AI 讀你的文件，所以要先告訴它用哪個 AI。**在網頁上填一次就好。**

1. 去 **[Google AI Studio](https://aistudio.google.com/apikey)** 申請一把 API Key（**免費**，Google 帳號登入就能拿）
2. 回到你的知識庫網頁 → 左側「**設定**」→ 找到「**萃取引擎**」
3. 選 **Gemini**，貼上金鑰，儲存
4. 如果小幫手已經連上了，點選單列圖示 →「**連上知識庫**」用同樣帳密重連一次，設定就生效

> 沒做這一步的話：小幫手會顯示「⚠ 萃取引擎未就緒」，或加了資料夾一直沒有「已萃 N 檔」。

## 📌 已經裝過的人：怎麼換到最新版

**重跑一次安裝就好**（不用重裝小幫手、資料不會掉）：

1. 到 https://install.arcrun.dev ，用你原本的 email 和辨識碼，按「**開始安裝／更新**」
2. 跑完後，小幫手點「**連上知識庫**」重連一次

> ⚠️ **這一步請務必做**：新版加強了安全性（你的知識庫不再能被外人讀取），
> 舊版實例沒更新的話會連不上、搜不到東西。

## 常見疑問

**Q：我的檔案會被上傳嗎？**
不會。AI 在你自己的電腦上讀檔、整理成知識卡，只有整理後的重點（一句話定義、要點、關聯）會上雲。

**Q：這會花我錢嗎？**
Cloudflare 免費方案就夠用。

**Q：不想同步某個資料夾了？**
點選單列圖示 → 該資料夾 → 「刪除這個知識庫」，就從清單移除。

**Q：我要怎麼移除整個東西？**
跟我說，我給你清理步驟（會刪掉你 Cloudflare 帳號裡的相關服務）。
